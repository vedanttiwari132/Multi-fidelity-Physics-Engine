# Multi-fidelity-Physics-Engine
A physics engine that aims to simulate almost everything physics while still user friendly enough for teachers and students

## Demo: Knockout Physics (browser boxing)

[`boxing/`](boxing/) contains a first-person, physics-driven boxing game built on a small Verlet particle engine (`boxing/src/physics.js`). See [`boxing/README.md`](boxing/README.md) to run it.
